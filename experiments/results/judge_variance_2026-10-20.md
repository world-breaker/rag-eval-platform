# 裁判多次采样的方差实测：本地 1.5B 裁判 N=7（离线臂）

- 生成日期：2026-10-20
- 复现：`python experiments/run_generation_eval.py --no-api --judge-samples 7 --out <临时目录>`
- 结果文件：`experiments/results/judge_variance_2026-10-20.json`（紧凑版：只存逐单元 7 次裁判原始档位与聚合数字，不含答案/上下文全文）
- 前置报告：`experiments/results/generation_eval_2026-10-19.md`（N=1 的三臂对照）

## 一、一句话结论

把同一答案的裁判调用从 1 次改成 7 次取中位数，**裁判自身的抽样噪声确实降下来了（MAE 的抽样 sd 降 29%、r 的抽样 sd 也降 29%），但代价是判分开销线性增长，而且整体结论一点没变**：本地 1.5B 裁判与强裁判的 correlation 依然在近零量级（|r| < 0.25），MAE 依然高于规则臂一倍，`unanswerable#2` 这类幻觉在 N=7 下反而被**更放行**（3 → 4）。所以「本地 1.5B 不适合作裁判」这个结论**对聚合方式稳健**——不是 N=1 运气不好。

## 二、实验设置（口径先摆清楚）

| 项 | 值 |
|---|---|
| 命令 | `python experiments/run_generation_eval.py --no-api --judge-samples 7 --out <临时目录>` |
| 运行的臂 | `rule, local`（**不调 API**，费用 0；本轮只测本地裁判的方差） |
| 样本数 | 33（`realistic` 14 + `near_dup_stress` 8 + `sample` 5 + `unanswerable` 6） |
| 每样本每维度裁判调用次数 | 7（3 维 × 33 条 = 99 个「样本×维度」单元，共 693 次裁判调用） |
| 裁判采样温度 | `judge_temperature = 0.8`（`judge_samples > 1` 时生效；N=1 仍走贪心） |
| 生成端解码 | 贪心（temperature=0、`do_sample=False`）→ **运行间方差为 0** |
| 总耗时 | 149.3s（逐样本计时合计 132.3s：生成 54.2s、裁判 78.1s；其余为模型加载与检索，**未单独计时**） |
| 兜底 | `n_fallbacks = 0`（无启发式兜底、无无法解析的维度） |
| 答案可比性 | 33 条答案与已提交 N=1 结果**逐条字符串相同** → 与 `generation_eval_2026-10-19.json` 的臂 B/N=1 分数可直接对照 |

因为生成端是贪心解码，**同一份答案**在两次运行里完全一致，所以下面所有差异都只来自「裁判这一侧」的采样，不掺杂生成随机性。

## 三、item 级抽样噪声（99 个单元格，每格 7 次采样）

| 指标 | 值 |
|---|---|
| 7 次采样**完全相同**的单元格 | 38 / 99 = **38.4%** |
| 极差（max − min）均值 | **0.86 档** |
| 极差分布 | 0 档 **38**、1 档 **37**、2 档 **24** |
| 每单元格抽样标准差均值（faithfulness） | **0.414** |
| 每单元格抽样标准差均值（relevance） | **0.322** |
| 每单元格抽样标准差均值（completeness） | **0.285** |
| 全部 99 个单元格里的最大标准差 | **0.926**（completeness） |

> 标准差口径：7 个观测的**总体标准差**（除以 7，不是除以 6）。若改用样本标准差（除以 6），上表三个均值会各放大到 0.447 / 0.348 / 0.308，最大 0.976——量级不变，但引用时请连口径一起说。

怎么读这张表：

- **38.4% 的单元格七次采到同一个档位**，说明裁判对相当一部分样本给出的是「钉死的答案」而不是摇摆——噪声集中在剩下的六成里。
- **极差只有 0/1/2 三档，没有出现 ≥3 档的跳变**：本地裁判的摇摆是「相邻一档抖动」，不是「1 分和 5 分随机跳」。
- **极差 <= 1 的占 75/99 = 75.8%**：这就是「多采样取中位数只值这么点钱」的物理来源——单次抽样最多错一档的地方，中位数也修不出多少东西来。

## 四、median-of-7 与 N=1（greedy）的差别：33 条里 faithfulness 变了 4 条

| 样本 | greedy（N=1，已提交） | median-of-7（本轮） | 方向 |
|---|---|---|---|
| `realistic#10` | 4 | 3.0 | 调低 |
| `realistic#11` | 3 | 4.0 | 调高 |
| `realistic#12` | 5 | 4.0 | 调低 |
| `unanswerable#2` | **3** | **4.0** | **调高（更放行幻觉）** |

`unanswerable#2` 是「川菜回锅肉配料」那条：知识库里只有 AI/大模型文档，模型整段编了菜谱，强裁判给 faithfulness=1。**N=1 greedy 给 3，N=7 中位数给 4** —— 采样的中位数把这条幻觉往「更像有据」的方向推了一档。

这一点必须单列：**多采样取中位数不是「只会去掉坏运气」的纯增益**。它对一条明确该判低分的编造答案，给出了比单次贪心更高的分。原因见第七节第一条：greedy 取的是众数，采样分布的中心本来就跟众数不在同一水平上。

同一件事按三个维度汇总（「变化明细」列均为 N=1 greedy → median-of-7）：

| 维度 | 变化条数 | 均值 N=1 → N=7 | 变化明细 |
|---|---|---|---|
| faithfulness | **4/33** | 3.1212 → 3.1212 | `realistic#10` 4→3、`realistic#11` 3→4、`realistic#12` 5→4、`unanswerable#2` 3→4 |
| relevance | **7/33** | 3.0000 → **2.8485** | `realistic#3` 5→4、`realistic#9` 5→3、`realistic#11` 3→4、`realistic#12` 5→4、`near_dup_stress#8` 3→2、`sample#4` 3→4、`unanswerable#2` 5→3 |
| completeness | **3/33** | 2.5758 → 2.5758 | `realistic#2` 5→3、`realistic#3` 3→4、`realistic#6` 3→4 |

两条必须说清的读法：

- **relevance 均值降 0.1515（−5.1%），说明中位数不是单向抬高**：它把高估的部分拉回来了（`realistic#9` 5→3、`near_dup_stress#8` 3→2），也把低估的抬上去（`sample#4` 3→4）。所以「取中位数 = 整体更严」也不成立，方向取决于每个 item 自己的 7 次分布。
- **`unanswerable#2` 在两个维度上反向移动**：faithfulness 3→**4**（更放行幻觉）、relevance 5→**3**。因此「中位数让裁判更保守」这个直觉**不成立**——它只是把 7 次观测的中位点取出来，方向由分布决定。这也是本文最该被记住的一点：**聚合只能减抖，不能纠正方向**。

本报告的对照与结论仍只展开 faithfulness——它是三臂对照、分段分析和结论都用的那一个维度；另两维在此只给变化清单，不单独做与强裁判的一致性对照。

## 五、整体指标对照（faithfulness vs 强裁判 C）

| 估计器 | mean | exact | ±1 | MAE | r |
|---|---|---|---|---|---|
| N=1 greedy（已提交） | 3.1212 | 0.2121 | 0.4848 | 1.8182 | −0.0326 |
| median-of-7（本次） | 3.1212 | 0.1818 | 0.4242 | 1.9394 | −0.1436 |

- **均值一模一样（3.1212）**，但那是巧合级的抵消：4 条变化里两条调高两条调低。
- **一致性指标没有变好，反而略差**：exact 0.2121 → 0.1818、±1 0.4848 → 0.4242、MAE 1.8182 → 1.9394、r −0.0326 → −0.1436。
- 这个「略微变差」**不能读成「N=7 比 N=1 差」**：N=1 在这里是一个确定的估计器（贪心），不是采样分布的一次抽样，两者的差别是**估计器不同**，不是准确度排序（见第七节第一条）。

## 六、只重抽裁判输出：抽样波动有多大（B=4000，seed=7）

做法：**固定这 33 条样本与它们的答案**，在每个 item 内部对已采到的 7 个裁判观测做有放回重抽，重算 MAE 与 r，重复 B=4000 次（`random.seed(7)`）。这样量的纯粹是「如果当初裁判多抽/少抽几次，指标会飘多少」。

| 估计器 | MAE 均值 | MAE 抽样 sd | r 均值 | r 抽样 sd |
|---|---|---|---|---|
| single（N=1） | 1.9337 | 0.0869 | −0.1520 | 0.0537 |
| median-of-3 | 1.9262 | 0.0745 | −0.1470 | 0.0461 |
| median-of-7 | 1.9207 | 0.0619 | −0.1430 | 0.0383 |
| median-of-15 | 1.9182 | 0.0513 | −0.1401 | 0.0314 |

- **MAE 的抽样 sd 降幅**（相对 single）：N=3 **−14%**、N=7 **−29%**、N=15 **−41%**。
- **r 的抽样 sd 降幅**：N=7 **−29%**（0.0537 → 0.0383）。
- **单次抽样下 r 的 90% 区间**：[−0.244, −0.066]；**median-of-7 下**：[−0.206, −0.081]。**单次抽样 r < 0 的比例 99.9%** —— 也就是说「本地裁判与强裁判负相关」这个方向本身不是抽出来的意外，但幅度确实被抽样噪声撑宽了。
- 注意 single 的 r 均值是 −0.1520，而第五节里 N=1 greedy 的 r 是 −0.0326。**这两个数不是同一个东西**：前者是「采样分布下一次抽样的期望」，后者是「贪心众数那一次」。差 0.12 就是第七节第一条说的那个水平差。

## 七、四条解释性事实 + 方法局限

**1）greedy 的 N=1 不是「采样分布的一次抽样」。** 它取众数，运行间方差为 0（重跑逐条一致），但它与采样分布的典型抽样在**水平**上不同：greedy 的 r = −0.0326，而采样分布下 single 的 r 均值 = −0.1520。所以本报告**不能**说「N=1 更准」或「N=7 更准」——只能说**这是两个不同的估计器**，一个低方差但有水平偏移，一个无偏但每次都在抖。要在两者间选，得先明确「你更怕系统偏移还是更怕抖动」，本报告没有做这个裁决。

**2）降噪是真的，但边际递减。** N=3 只降 14%，N=7 降 29%，N=15 降 41%——大致是「翻 5 倍调用换 41% 的 sd 下降」。要把噪声压下去就得付线性增长的判分开销；在 33 条样本、本地裁判这种量级上，这笔钱花得并不值。

**3）结论方向不变。** median-of-7 仍然是「近零相关（|r| = 0.14）+ MAE 1.94，比规则臂的 0.92 高一倍」，且 `unanswerable#2` 反而更放行。所以「本地 1.5B 不适合作裁判」**对聚合方式稳健**：换聚合方法救不了它，问题在裁判分辨力本身。

**4）精度边界。** 33 条样本 + 裁判抽样噪声下，**r 不应被引用到小数点后四位**。引用时给量级（|r| < 0.25）加 90% 区间；本报告表格里保留四位只是为了跟已提交报告逐位对照，不是精度声明。

**方法局限（必须一并说）**：

1. **只有 7 个观测做非参数 bootstrap**：每个 item 的「分布」是用 7 个点近似的，尾部行为完全看不到；bootstrap 出来的 sd 是**下界性质**的估计，真实抽样波动只会更大。
2. **B=4000、seed=7 已固定**：`experiments/bootstrap_judge_variance.py`（默认 `--seed 7 --boot 4000`）能逐位复算第六节那张表。更换 seed 会让表内数值在 **≤1e-3 量级**抖动（均值与 sd 都变，但「N 越大 sd 越小」「近零相关」的结论不受影响）；保留四位小数只是为了与脚本输出对齐，不代表精度。
3. **n=33 只给量级**：33 条里 4 条变化、其中 1 条方向反转，这种计数不足以支撑比例推断；不要把它读成「12% 的样本会被中位数改变」。
4. **本轮只跑离线臂**：没有重新调用强裁判，臂 C 的分是 2026-10-19 归档值（强裁判每样本 1 次、temperature=0）。所以「median-of-7 vs 强裁判」的对照里，**强裁判那一侧本身没有方差信息**。
5. **本地裁判与生成模型同款（自评）**：绝对分不可作为质量证据，只能看它与强裁判的偏离方向与幅度。
6. **裁判采样温度固定 0.8**（仓库默认），没有扫温度；温度更低时 item 级噪声可能更小，本报告的降幅数字只在 0.8 下成立。
